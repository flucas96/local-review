# Local Review identity

The code chevrons inside a conversation bubble continue the mark used in the product demo. The mint-on-navy listing icon uses a simple silhouette without lettering so it remains readable at small sizes.

- `icon.svg`: editable vector source on a rounded navy tile.
- `icon.png`: 256 × 256 RGBA PNG used by the extension manifest and Marketplace listing.
- `review.svg`: simplified 24 × 24 monochrome icon for the Review view.

Palette: navy `#101B29`, teal `#264751`, mint `#75C7D2` and `#B7F0E9`, code strokes `#E5FBF7`.

Export `icon.svg` at 256 × 256 with transparency to regenerate `icon.png`. The PNG was rendered from this vector source; it contains no external stock imagery or generated bitmap assets. The view icon intentionally omits the tile so VS Code can adapt its single-color symbol to the workbench theme.
